HTML

HTML (HyperText Markup Language) is the standard markup language used to structure and present content on the World Wide Web. First created by Tim Berners-Lee in 1991, HTML forms the core backbone of every website on the internet today.


Key Concepts

  1. Not a Programming Language: HTML is a markup language—it defines the structure and layout of web content rather than executing logic.
  2. Element & Tag Structure: Content is wrapped in tags like p (paragraph), h1 (heading), and a (link).
  3. DOM (Document Object Model): Browsers parse HTML code into a tree structure that CSS can style and JavaScript can manipulate dynamically.
  4. Semantic Web: HTML5 introduced structural tags like header, nav, main, and footer to improve accessibility and SEO.
